# 3D Earth Scroll Demo

使用原生 WebGL 与 `<canvas>` 构建的最小可用 3D 地球滚动交互动效示例。无需打包或服务器，直接打开 `index.html` 即可运行（已内置 base64 纹理与单脚本以规避 file:// 环境下的 CORS/模块限制）。

## 🚀 快速使用

1. 确保浏览器支持 WebGL（现代桌面/移动浏览器均已支持）。
2. 在本项目根目录双击或拖拽 `index.html` 至浏览器中打开。
3. 滚动页面，体验 3 屏段落与 3D 地球的联动变化。

## ✨ 功能速览

- WebGL 手写着色器，与 NASA 高清地球纹理搭配渲染大气光晕。
- 三段滚动分镜：缩放特写 → 俯视亮点 → 拉远 CTA。
- 平滑阻尼滚动，镜头与地球旋转自然过渡。
- 代码完全模块化：着色器、几何体、滚动控制、配置分离。

## 🔧 可调参数

所有核心参数集中在 `app.js` 顶部的配置常量中：

- `CAMERA_CONFIG`：视场角、近远裁剪面、镜头距离及俯视角限制。
- `EARTH_CONFIG`：自转速度、滚动额外旋转角度、缩放比例。
- `ATMOSPHERE_CONFIG`：气层强度、颜色、半径增益。
- `SCROLL_SPRING`：滚动阻尼系数，可调节动效的跟随感。

调整后刷新页面即可看到效果变化。

## 🧱 文件结构

```
.
├─ index.html         # 页面结构与 WebGL canvas
├─ styles.css         # 滚动分镜与视觉样式
├─ app.js             # 合并后的主脚本（包含原模块逻辑）
└─ assets/
    ├─ earth_daymap_2048.jpg        # NASA 蓝色星球纹理
    └─ earth_texture_base64.js      # 供 file:// 环境使用的内嵌纹理数据
```

> 附：`src/` 目录仍保留了按模块拆分的源码（便于阅读或在需要时自行打包成模块体系）。
